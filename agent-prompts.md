Asosiy mavzular:

1. Appwrite authentication va email orqali verification code bilan login.
2. Personal Account va onboarding flow.
3. Profile sahifasi va profile ma'lumotlarini yangilash.
4. Appwrite Function bilan ishlash va authentication xatolarini debugging qilish.
5. Yangi va mavjud foydalanuvchilar uchun login flow va `redirect` bilan ishlash.
6. Header'dagi authentication holatini to‘g‘ri ko‘rsatish.
7. `TASK.md` talablarini tekshirish va asosiy edge case'larni ko‘rib chiqish.
